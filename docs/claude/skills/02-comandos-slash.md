# Comandos

> Referência completa dos comandos disponíveis no Claude Code, incluindo comandos integrados e skills agrupadas.

Os comandos controlam o Claude Code dentro de uma sessão. Eles fornecem uma maneira rápida de alternar modelos, gerenciar permissões, limpar contexto, executar um fluxo de trabalho e muito mais.

Digite `/` para ver todos os comandos disponíveis para você, ou digite `/` seguido de letras para filtrar.

Um comando é reconhecido apenas no início da sua mensagem. O texto que segue o nome do comando é passado para ele como argumentos. A partir da v2.1.199, [skills](https://code.claude.com/docs/pt/skills#pass-arguments-to-skills) são a exceção: uma invocação de skill seguida por mais skills, como `/skill-a /skill-b do XYZ`, carrega cada skill nomeada no início e passa o texto final para cada uma como argumentos. Até seis skills podem ser encadeadas.

Se você enviar um comando enquanto Claude está respondendo, ele é enfileirado e executado após o turno atual terminar. Alguns comandos, como `/status`, `/tasks` e `/usage`, são executados imediatamente sem interromper a resposta.

<h2 id="commands-across-a-typical-workflow">
  Comandos em um fluxo de trabalho típico
</h2>

A maioria dos comandos é útil em um ponto específico de uma sessão, desde a configuração de um projeto até o envio de uma alteração.

**Primeira sessão em um repositório.** Execute `/init` para gerar um `CLAUDE.md` inicial, depois `/memory` para refiná-lo. Use `/mcp` para configurar quaisquer servidores que o projeto necessite, peça a Claude para criar quaisquer [subagentes](https://code.claude.com/docs/pt/sub-agents) que você queira, e execute `/permissions` para definir suas regras de aprovação.

**Durante uma tarefa.** `/plan` alterna para o Plan Mode antes de uma grande alteração. `/model` e `/effort` ajustam qual modelo você está usando e quanto raciocínio ele aplica. Quando a conversa fica longa, `/context` mostra o que está preenchendo a janela e `/compact` a resume para liberar espaço. Use `/btw` para uma observação rápida que não deve ser adicionada ao histórico de conversa.

**Executando trabalho em paralelo.** Claude delega tarefas secundárias para [subagentes](https://code.claude.com/docs/pt/sub-agents), e `/tasks` lista o trabalho em segundo plano da sessão atual, incluindo subagentes que foram concluídos. `/background` desanexa a sessão inteira para continuar em execução como um [agente de fundo](https://code.claude.com/docs/pt/agent-view) e libera seu terminal. Para uma grande alteração que abrange a base de código, `/batch` a decompõe em unidades independentes e executa cada uma em seu próprio [worktree](https://code.claude.com/docs/pt/worktrees). Consulte [Executar agentes em paralelo](https://code.claude.com/docs/pt/agents) para saber como essas abordagens se relacionam.

**Antes de você enviar.** `/diff` mostra o que mudou, `/code-review` verifica o diff quanto a bugs de correção e limpezas e pode aplicar as descobertas com `--fix`, `/review` fornece uma revisão rápida de uma única passagem, somente leitura de uma solicitação de pull do GitHub, `/code-review <level> <pr#>` executa uma revisão multi-agente de uma, e `/security-review` verifica o diff quanto a vulnerabilidades de segurança. `/code-review ultra` executa uma revisão multi-agente na nuvem.

**Entre sessões.** `/clear` começa do zero em uma nova tarefa enquanto mantém a memória do projeto. `/resume` e `/branch` permitem que você retorne ou bifurque uma conversa anterior. `/teleport` puxa uma sessão web para este terminal, e `/remote-control` permite que você continue esta sessão local de outro dispositivo.

**Quando algo está errado.** `/rewind` reverte o código e a conversa para um checkpoint, ou resume parte da conversa. `/doctor` executa uma verificação de configuração que diagnostica problemas de instalação e configuração e pode corrigi-los, `/debug` diagnostica problemas de tempo de execução, e `/feedback` relata um bug com contexto de sessão anexado.

<h2 id="all-commands">
  Todos os comandos
</h2>

A tabela abaixo lista todos os comandos incluídos no Claude Code. A maioria são comandos integrados cujo comportamento é codificado na CLI. Dois tipos de entradas são marcados:

* **[Skill](https://code.claude.com/docs/pt/skills#bundled-skills)**: uma skill agrupada. Funciona como skills que você escreve: um prompt entregue ao Claude, que Claude também pode invocar automaticamente quando relevante.
* **[Workflow](https://code.claude.com/docs/pt/workflows#bundled-workflows)**: um [workflow dinâmico](https://code.claude.com/docs/pt/workflows) agrupado que se expande entre muitos subagentes e é executado em segundo plano.

Para adicionar seus próprios comandos, consulte [skills](https://code.claude.com/docs/pt/skills).

Na tabela abaixo, `<arg>` indica um argumento obrigatório e `[arg]` indica um opcional.

<Note>
  Nem todo comando aparece para todos os usuários. A disponibilidade depende da sua plataforma, plano e ambiente. Por exemplo, `/desktop` aparece apenas no macOS e Windows quando conectado com uma assinatura Claude, e `/upgrade` aparece apenas nos planos Pro e Max.
</Note>

<h2 id="mcp-prompts">
  MCP prompts
</h2>

Os servidores MCP podem expor prompts que aparecem como comandos. Estes usam o formato `/mcp__<server>__<prompt>` e são descobertos dinamicamente a partir de servidores conectados. Consulte [MCP prompts](https://code.claude.com/docs/pt/mcp#use-mcp-prompts-as-commands) para detalhes.
